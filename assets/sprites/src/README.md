# Editable sources

Aseprite working files for the sprites that previously had **no source at all**.

Before the refactor these six images did not exist as files. They were drawn at
runtime by `Image.set_pixel` loops inside `bat.gd`, `spitter.gd`, `projectile.gd`,
`shockwave.gd` and `world.gd` — which meant changing the bat's silhouette was a
matter of editing arithmetic, and handing the art to anyone who draws was
impossible.

`tools/export_generated_textures.gd` ran that original code once and baked the
result to PNG, pixel for pixel. These `.aseprite` files wrap those PNGs so the
art is editable from here on.

| Source | Exports to | Was generated by |
| --- | --- | --- |
| `bat.aseprite` | `../bat.png` | `bat.gd::_make_bat_texture()` |
| `spitter.aseprite` | `../spitter.png` | `spitter.gd::_make_spitter_texture()` |
| `projectile_blob.aseprite` | `../projectile_blob.png` | `projectile.gd::_make_blob_texture()` |
| `shockwave_ring.aseprite` | `../shockwave_ring.png` | `shockwave.gd::_make_ring_texture(128)` |
| `heart_full.aseprite` | `../heart_full.png` | `world.gd::_build_heart_textures()` |
| `heart_empty.aseprite` | `../heart_empty.png` | same, darker tint |

The other sprites in `../` (Cyn's frames, the pursuer, platforms, walls, punch
frames) were always real PNG files and have no Aseprite source here.

## Editing

Open a file, edit, then export over the PNG one directory up, keeping the name
and size. Nothing in code references these `.aseprite` files — the `.gdignore`
here keeps Godot from importing them — so the PNG is the only thing that has to
stay in place.

Each file carries an empty `Layer 1` left over from the canvas it was created
on; deleting it changes nothing.
